# 💀 CEMITÉRIOS GÓTICOS 💀

> **MÚSICA DE IA - OUÇA EM PAZ**

Um player de música visceral e brutal que celebra a estética gótica através de 38 composições geradas por IA, cada uma nomeada em homenagem aos cemitérios mais icônicos e sombrios do mundo.

---

## 🦇 O QUE É ISSO?

Uma experiência audiovisual **neon-brutalist** que mergulha nas profundezas da música gótica criada por inteligência artificial. Cada faixa carrega o nome e a energia de cemitérios históricos espalhados pelo globo - de Highgate em Londres ao Cemitério Central de Bogotá.

**38 CEMITÉRIOS. 38 HISTÓRIAS. 38 MELODIAS SOMBRIAS.**

---

## ⚰️ CARACTERÍSTICAS

### 🎨 Design Neon-Brutalist
- Estética cyberpunk gótica com cores néon vibrantes
- Fundo inspirado em Joy Division
- Animações de glitch e rotação contínua
- Interface brutalista e minimalista

### 🎵 Player Customizado
- **Botões giratórios** com animações hypnóticas
- Integração completa com YouTube API
- Controles: Play/Pause, Stop, Anterior, Próximo, Tocar Todas
- Visualização de faixa atual em destaque

### 🌍 38 Cemitérios do Mundo
Cada música representa um cemitério histórico:
- 🏴󠁧󠁢󠁥󠁮󠁧󠁿 Highgate (Londres)
- 🇫🇷 Père Lachaise (Paris)
- 🇮🇹 Cimitero Monumentale (Milão)
- 🇧🇷 Cemitério da Consolação (São Paulo)
- ... e mais 34 locais assombrados

## 🚀 COMO USAR

1. **Clone este repositório das sombras:**
```bash
git clone [seu-repo-aqui]
```

2. **Abra o arquivo HTML:**
```bash
# Simplesmente abra index.html no seu navegador
# Ou use um servidor local:
python -m http.server 8000
```

3. **Mergulhe na escuridão:**
   - Clique em qualquer cemitério da grid
   - Use os botões giratórios para navegar
   - Deixe a música gótica invadir sua alma

---

## 🎮 CONTROLES

| Botão | Cor | Função |
|-------|-----|--------|
| **PLAY** | 🟢 Verde Néon | Play/Pause da faixa atual |
| **STOP** | 🔴 Vermelho Néon | Para completamente a música |
| **ANT** | 💜 Roxo Néon | Faixa anterior |
| **PROX** | 🔵 Azul Néon | Próxima faixa |
| **ALL** | 🟡 Amarelo Néon | Toca playlist completa |

## 🦴 CARACTERÍSTICAS TÉCNICAS

### Animações CSS
- **spinCircle**: Rotação contínua dos botões (360°)
- **spinCounter**: Contra-rotação do texto interno
- **glitchText**: Efeito glitch no título principal
- **pulse**: Pulsação do indicador "PLAYING"

### YouTube API Integration
- Carregamento dinâmico de vídeos
- Detecção automática de fim de faixa
- Controle programático de play/pause/stop
- Playlist sequencial automática

### Responsividade
- Grid adaptativo (auto-fill, minmax)
- Breakpoint mobile em 768px
- Controles redimensionáveis
- Layout fluido e flexível
